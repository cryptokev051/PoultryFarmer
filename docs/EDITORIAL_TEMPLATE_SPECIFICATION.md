# Poultry Farmer Editorial Template Specification

Date: 19 November 2026  
Applies to: Phase 2B2 block-theme templates and patterns

## Template system

### Poultry Type Hub

File: `theme/poultryfarmer/templates/poultry-hub.html`

Use for the Kienyeji, layers, broilers and hatching child Pages. The template supplies the global header/footer, breadcrumbs, Page title, excerpt and editor-managed Page content. It deliberately leaves production-specific content in the WordPress editor rather than hardcoding four variants in the theme.

Each poultry-type hub should contain:

1. One H1 supplied by the Page title.
2. A specific introduction and production-model overview.
3. Startup and management considerations.
4. A category-filtered Query Loop for related published guides.
5. Links to feeding, housing, health and records where relevant.
6. A factual financial-planning note without unverified figures.
7. Links to the other farming-model hubs.

Do not publish empty sections. If a related Query Loop has no Posts, show a useful native Query No Results message.

### Editorial Section Hub

File: `theme/poultryfarmer/templates/section-hub.html`

Use for permanent editorial directories such as Management, Prices and Calculators. The Page title, excerpt and block content remain editable. The Calculators page must retain a non-functional coming-soon state until logic exists in the future `poultryfarmer-core` plugin.

### Single guide

File: `theme/poultryfarmer/templates/single.html`

The single-Post experience includes:

- semantic breadcrumbs;
- primary categories;
- one H1;
- a useful excerpt/standfirst;
- named author and published date;
- an updated date only when the modified timestamp is later than publication;
- constrained reading width;
- responsive tables;
- an author profile only when the author has a biography;
- category-based related guides or a clear empty state;
- previous/next guide navigation.

The theme never fabricates reviewer information. Reviewer credit should appear only when a real review happened and the editorial workflow can store the name and date accurately. No empty author box is rendered.

## Reusable patterns

The Phase 2B2 additions are intentionally limited:

| Pattern | Purpose |
|---|---|
| Key Farming Considerations | Summarize decisions that materially affect a flock or production model. |
| Cost Breakdown | Group setup, recurring and working-capital cost areas without inserting market figures. |
| Practical Checklist | Provide ordered, actionable checks. |
| Common Mistakes | Explain avoidable planning or management errors. |
| Example Calculation | Show assumptions and reproducible arithmetic as editorial content only. |

Existing Poultry Farmer patterns remain available for assumptions, sources and methodology, risks and limitations, sensitivity scenarios, toolkit recommendations and related guides. Wording was adjusted where inherited “analysis” terminology did not fit the publication.

Patterns are editorial scaffolds, not locked data. Editors must replace prompts, remove unused sections and add attributable evidence before publication. Calculator formulas and interactive financial logic do not belong in a theme pattern.

## Article standards

### Attribution

- Use a real named author.
- Add a concise biography only when it is useful and accurate.
- Do not invent veterinary, financial or farming credentials.
- Add reviewer information only after a documented review.
- Use publication and modification dates generated by WordPress; do not type decorative dates into article copy.

### Sources and evidence

For factual guidance, record the source organization or author, publication title, publication date, link where appropriate, and the claim it supports. State when figures are assumptions, examples or observations. Include limitations when evidence may not transfer across production systems, counties, seasons or market conditions.

### Tables and calculations

Use semantic table headings and row headers. State units, data period and source. Wide tables scroll horizontally on small screens and display a swipe prompt. Example calculations must identify every input and must not be presented as a live calculator.

### Images

Use meaningful featured images when available. Write useful alternative text for informative images; leave the alternative text empty only for genuinely decorative placeholders. Do not publish unlicensed or unrelated stock imagery.

## Archive and discovery behavior

- `/guides/` uses the native Posts archive and pagination.
- Category archives show Posts explicitly classified in that category.
- Search results reflect the user query and provide a useful empty state.
- Related guides use shared categories only; the theme does not fall back to random recent Posts.
- The related-guides empty state links to the Guides directory.
- “Hello world!” is removed only in the local fixture when it is still the untouched default Post.

## Editor checklist

Before publishing a Page or Post:

1. Confirm one H1 and a logical H2/H3 sequence.
2. Confirm the route and primary search intent do not compete with an existing page.
3. Replace all fixture labels and synthetic copy.
4. Add a useful excerpt and relevant categories.
5. Verify every internal link and remove empty sections.
6. Add named sources, dates, assumptions and limitations where needed.
7. Review author and reviewer attribution for accuracy.
8. Check tables, images and links at desktop and mobile widths.
9. Configure metadata in the selected SEO plugin.
10. Obtain editorial approval before production publication.

## Technical limitations

- The removable `poultryfarmer-starter` setup plugin has been verified on a fresh isolated install. It creates editable hub Pages and slug-resolved category Query Loops; it is not required for later editing or publishing and does not change these theme templates.
- Authenticated Site Editor, Page editor and Post editor access are verified in the isolated Profile B runtime.
- The protected block-pattern endpoint returned all 21 registered Poultry Farmer patterns in an authenticated session. The five Phase 2B2 patterns and the existing Sources & Methodology pattern were inserted into a draft, edited, saved, reopened and rendered on the front end.
- Draft Pages retained `poultry-hub` and `section-hub` template assignments after save/reopen. A category-filtered Query Loop also retained its taxonomy filter and Query No Results state.
- A synthetic guide retained title, slug, excerpt, category, author, featured image, source pattern and responsive table after publication, edit and reopen. The updated date appeared only after the later edit.
- WordPress emitted a repeated non-blocking editor warning about `global-styles-css-custom-properties-inline-css` being added to the iframe. No theme source references or enqueues that handle; no PHP error, save failure or front-end error accompanied it.
- All 21 pattern source files passed static header validation and the active theme produced no PHP errors during the tested front-end routes.
- This phase does not add a source registry, editorial workflow plugin, custom post type, schema system or SEO metadata system.
